# Прогнозирование оттока клиентов стримингового сервиса

ML-проект на данных о 5000 подписчиков: анализ и предсказание оттока (churn), поиск поведенческих драйверов ухода.

## Ключевые выводы
- **Отток определяется вовлечённостью, а не демографией.** Три независимых метода (EDA, коэффициенты логрега, важность признаков леса) сошлись: сильнейшие предикторы — время просмотра и давность последнего входа.
- **Тариф:** Basic уходит в 61,8% случаев против 43,7% у Premium.
- **Оплата:** Crypto (59,7%) и Gift Card (57,8%) уходят на ~15 п.п. чаще банковских карт (~43,6%).
- **Регион, возраст, устройство — шум:** значимых различий нет.
- **Модель:** Random Forest — accuracy ≈0.98, recall по оттоку ≈0.97; заметно лучше логрега (≈0.89) → связи в данных нелинейные.

## Методы
EDA (`groupby`, `pd.cut`) · one-hot encoding · train/test split · масштабирование · Logistic Regression · Random Forest · сравнение моделей · извлечение драйверов (коэффициенты + feature importances).
